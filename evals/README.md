# 证据核对与复跑

quick-evidence.json 保存新版短文本对照的预定方案、30份冻结技能文件、输入哈希、13次正式尝试，以及12个有效输出的使用量和逐项评分。评分由执行者人工复核，尚未独立盲评。该包不包含登录信息、本机绝对路径或会话标识。

glm-zcode-evidence.json 保存用户提供的旧版测试方案、输入素材、24份回复和原评分。公开版本替换了路径、项目名及服务账号标签，模块甲与模块乙保留为两个不同名称。它提供最终评分，个别评分员的独立原始记录和实际产物未提供。

## 核对已有记录

使用 Node.js 20 或以上版本，从仓库根目录运行以下命令。该操作读取本地证据，无需网络和模型调用。

    node evals/verify.cjs

脚本重算两批分数与usage，核对新版输入重建哈希、冻结版本、字数和有效结果数。有关语义完整性、范围保留的判断，请参照预定标准阅读每条result。脚本通过仅代表这些机械核对项通过。

## 复跑新版快速对照

复跑需要已登录且支持所列参数的 Codex CLI，以及可用的 GPT-6.2 Sol。执行12次短文本请求会产生实际模型使用量，基础设施失败按原方案最多重试一次。以下命令采用冻结版本与相同的预加载方式，输出到指定的新目录。

    node evals/replay.cjs --cli /absolute/path/to/codex --output /absolute/path/to/new-evidence

Windows 请为带空格的路径加双引号，并指向真正的codex.exe。也可由已配置的CODEX_APP_RUNTIME_CLI_PATH提供入口。脚本保留输入、CLI事件、使用量、输出及失败，后续按protocol.tasks中的原标准评分。

复跑工具的输入重建与语法检查已在发布时核对。完整调用逻辑沿用本次实测流程，发布后没有为验证脚本额外发起一批付费模型调用。模型服务与公共宿主上下文可能变化，因此输出和总token可能不同。

## 测试与发布版本

当前根目录的SKILL.md、models.md、cache.md及references中的文件应与quick-evidence.json内的冻结文本一致。核对脚本会检查这些文件。后续若更新技能，先保留这份快照，再为新版本记录新的测试。

历史v2/v3汇总见根目录results.json，测试方法见docs/HISTORICAL-V3.md。
